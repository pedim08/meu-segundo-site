# meu-segundo-site
NOBRETECH — E-COMMERCE DE HARDWARE
====================================

Este projeto foi feito para funcionar como um projeto de PORTFÓLIO.

Arquivos:
- index.html
- style.css

TECNOLOGIAS
-----------
HTML5 + CSS3.
Não foi utilizado JavaScript.

INTERAÇÕES FEITAS APENAS COM HTML/CSS
-------------------------------------
- Navegação por âncoras.
- Busca envia para a área de produtos.
- Menu de categorias.
- Modal de login.
- Modal de favoritos.
- Quick view dos produtos.
- Carrinho lateral.
- Modal de checkout.
- Seleção de forma de pagamento.
- Formulários de login/checkout.
- Layout responsivo.

LIMITAÇÃO IMPORTANTE
--------------------
HTML e CSS, sozinhos, NÃO conseguem implementar um carrinho real com banco
de dados, cálculo dinâmico de quantidade/preço ou processamento real de Pix,
cartão ou boleto.

Nesta versão, essas partes são uma DEMONSTRAÇÃO VISUAL/INTERATIVA para
portfólio. Para transformar em uma loja real seriam necessários JavaScript
e um backend/API, além de um gateway de pagamento.

COMO PUBLICAR
-------------
1. Crie um repositório no GitHub.
2. Envie index.html e style.css.
3. Vá em Settings > Pages.
4. Escolha Deploy from branch.
5. Selecione a branch main e a pasta /root.
6. Salve.

PERSONALIZAÇÃO
--------------
Troque:
- Links do GitHub.
- LinkedIn.
- Nome/e-mail.
- Produtos.
- Preços.
- Quantidades.
- Textos.

IDENTIDADE
----------
O layout foi construído a partir da imagem fornecida pelo usuário:
- cabeçalho semelhante;
- barra de pesquisa;
- menu laranja;
- banner gamer;
- categorias;
- produtos em cards;
- ofertas;
- métodos de pagamento;
- benefícios;
- rodapé.

A referência comercial usada para a estrutura de categorias é a organização
comum de lojas de hardware: processadores, placas de vídeo, placas-mãe,
memórias, armazenamento, fontes, gabinetes e periféricos.
